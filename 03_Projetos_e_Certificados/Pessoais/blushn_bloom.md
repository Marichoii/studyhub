# Blush'n Bloom

## Categoria

Projeto pessoal.

## Resumo

Blush'n Bloom e um simulador responsivo de recomendacao de maquiagem. A aplicacao gera sugestoes personalizadas a partir de caracteristicas e contexto informados pela pessoa usuaria, como tipo de evento, tom de pele, subtom, cor dos olhos e cor do cabelo.

## Objetivo

Criar uma experiencia web com interface limpa e intuitiva para apoiar escolhas de maquiagem de forma personalizada, reunindo formulario, regras de recomendacao, resultado e historico de simulacoes.

## Tecnologias

- React.
- Vite.
- Tailwind CSS.
- Node.js.
- Express.
- MongoDB Atlas.
- Vercel.
- Render.

## Funcionalidades

- Recomendacoes personalizadas de base, estilo, sombra e batom.
- Historico de simulacoes com data e detalhes.
- Interface responsiva para desktop e mobile.
- Separacao entre frontend, backend, servicos e regras de dominio.
