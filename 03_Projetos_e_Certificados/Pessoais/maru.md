# Maru

## Categoria

Projeto pessoal.

## Resumo

Maru e uma aplicacao em portugues para estudar japones do zero. O projeto organiza uma trilha de aprendizado com licoes, explicacoes, exercicios, pratica de kana, escrita, frases e revisao espacada.

## Objetivo

Criar uma ferramenta educacional progressiva para apoiar o estudo de japones, com foco em pratica guiada, acompanhamento de progresso e reforco dos erros.

## Tecnologias

- JavaScript.
- CSS.
- HTML.
- Node.js.
- Playwright.
- JSON para persistencia local de progresso.

## Funcionalidades

- Trilha com licoes organizadas por etapas.
- Exercicios de hiragana, katakana, kanji, frases e particulas.
- Canvas para pratica de escrita com suporte a mouse, toque e caneta.
- Revisao espacada para reforcar erros.
- Progresso local com XP, constancia e meta diaria.
- Testes automatizados e testes end-to-end.
