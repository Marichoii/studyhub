# Projetos e Certificados

Esta pasta concentra projetos academicos, projetos pessoais e certificados que servem como evidencias da trajetoria em TI.

## Organizacao

- [`Academicos`](./Academicos): trabalhos vinculados a disciplinas, bootcamps, TCC ou projetos integradores.
- [`Pessoais`](./Pessoais): estudos autorais, exercicios praticos, prototipos e projetos de portfolio.
- [`Trabalho_e_Mentoria`](./Trabalho_e_Mentoria): projetos desenvolvidos em contexto profissional, mentoria ou desafio tecnico.
- [`Certificados`](./Certificados): certificados, badges e comprovantes de formacao.

## Padrao de Registro

Cada projeto deve conter:

- objetivo;
- tecnologias usadas;
- contexto academico ou pessoal;
- instrucoes de execucao, quando houver codigo;
- evidencias de resultado;
- proximos passos ou melhorias.

Cada certificado deve conter nome, instituicao emissora, data de conclusao e link publico quando houver.
