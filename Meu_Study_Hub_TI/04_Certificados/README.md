# Certificados

Esta pasta deve reunir certificados, badges, cursos complementares e evidencias de formacao extracurricular.

## Padrao de Registro

Para cada certificado, registrar:

- nome do curso ou certificacao;
- instituicao emissora;
- data de conclusao;
- carga horaria, quando houver;
- competencias desenvolvidas;
- link publico ou arquivo comprobatorio, quando permitido.
