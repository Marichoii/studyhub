# Projeto Pessoal - Pedra, Papel e Tesoura em Python

## Contexto

Projeto pratico de Python baseado em um jogo simples de Pedra, Papel e Tesoura. O material atual mostra uma primeira versao executada no terminal, com entrada do usuario, escolha aleatoria do computador e impressao do resultado.

## Objetivo

Praticar estruturas condicionais, entrada de dados, numeros aleatorios, validacao de opcoes e organizacao de codigo em Python.

## Tecnologias

- Python 3.
- Terminal.
- Modulo `random`.

## Melhorias Recomendadas

- Validar se a entrada do usuario esta entre 0, 1 e 2 antes de comparar resultados.
- Criar uma lista com os nomes das opcoes para melhorar a exibicao.
- Corrigir a logica de vitoria para cobrir todos os casos possiveis.
- Permitir mais de uma rodada.
- Separar a regra do jogo em funcoes.
- Adicionar testes automatizados para as combinacoes de vitoria, derrota e empate.

## Relacao com o Study Hub

Este projeto entra como evidencia de aprendizado pratico em programacao. Ele tambem pode ser usado futuramente na disciplina de Testes e Qualidade de Software, aplicando testes automatizados sobre uma regra simples e bem definida.
