# Projeto 1 - Prototipo de Sistema Embarcado

## Objetivo

Documentar o primeiro prototipo pratico da disciplina, conectando um problema simples a uma solucao com sensor, atuador, microcontrolador ou simulacao.

## Tecnologias Possiveis

- Arduino ou ESP32.
- C/C++ para firmware.
- Wokwi ou TinkerCad para simulacao.
- Sensores, LEDs, botoes, displays ou atuadores.

## Etapas

- [ ] Definir problema e comportamento esperado.
- [ ] Montar circuito ou simulacao.
- [ ] Escrever codigo inicial.
- [ ] Testar funcionamento.
- [ ] Registrar evidencias e aprendizados.
