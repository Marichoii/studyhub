# Bootcamp I

## Objetivo da Disciplina

Organizar a base do Study Hub TI, estruturando a identidade profissional, a arquitetura do repositorio, a matriz de disciplinas e os materiais necessarios para a entrega inicial do projeto integrador.

## Materiais

- `Anotacoes`: registros sobre o enunciado, criterios de avaliacao e decisoes de organizacao.
- `Entregas`: documentos finais, checklist de submissao e evidencias preparadas para avaliacao.
- `Projetos`: estrutura logica do Hub, roteiro de apresentacao e itens de apoio ao pitch.

## Relacao com Carreira

Bootcamp I fortalece a organizacao profissional, a comunicacao tecnica e a capacidade de apresentar um projeto de forma clara para stakeholders. Esses pontos sao essenciais para desenvolvimento de software, pesquisa, trabalho em times multidisciplinares e construcao de portfolio.
