# Projeto 1 - Automacao de Testes

## Objetivo

Selecionar um projeto simples e aplicar testes automatizados para validar comportamentos principais, registrar falhas e demonstrar melhoria de confiabilidade.

## Tecnologias Possiveis

- PyTest para projetos Python.
- Jest para projetos JavaScript ou TypeScript.
- Cypress ou Selenium para testes de interface.
- GitHub Actions para execucao automatizada em pipeline.

## Etapas

- [ ] Escolher o projeto a ser testado.
- [ ] Definir cenarios principais.
- [ ] Escrever os primeiros casos de teste.
- [ ] Executar testes localmente.
- [ ] Registrar resultados e melhorias.
