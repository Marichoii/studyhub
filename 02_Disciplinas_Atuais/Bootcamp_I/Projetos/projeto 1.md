# Projeto 1 - Arquitetura do Study Hub

## Objetivo

Construir uma estrutura de repositorio clara, padronizada e apresentavel, capaz de reunir perfil profissional, disciplinas atuais, projetos, certificados e materiais de portfolio.

## Tecnologias e Ferramentas

- Git e GitHub.
- Markdown.
- Google Docs para documento base final.
- YouTube para pitch de apresentacao.

## Artefatos

- README principal do Study Hub.
- Documento final da Fase 1.
- Roteiro de apresentacao.
- Checklist de submissao.
- Estrutura padronizada por disciplina.
