# Entrega Intermediária - Criação de Repositório com Versionamento

## Objetivo

Evoluir o Study Hub TI para um repositório público, organizado, documentado e versionado, reunindo projetos acadêmicos e pessoais e disponibilizando uma página web por meio do GitHub Pages.

## Planejamento do repositório

A estrutura foi organizada em três áreas principais:

1. `01_Apresentacao_e_Perfil`: identificação, perfil profissional e contatos.
2. `02_Disciplinas_Atuais`: disciplinas do semestre, com separação entre atividades/entregas e anotações/resumos.
3. `03_Projetos_e_Certificados`: projetos acadêmicos, pessoais e certificados.

Os arquivos `README.md` orientam a navegação e explicam o objetivo de cada seção.

## Versionamento

O repositório utiliza Git e GitHub para registrar a evolução do Study Hub. A entrega intermediária adiciona a página web do portfólio em `docs/`, documentação específica da entrega e configuração de publicação automática.

### Versão 1.0

A versão 1.0 do projeto corresponde à estrutura do Study Hub com:
- arquitetura organizada de diretórios;
- documentação em Markdown;
- projetos e disciplinas registrados;
- página web estática;
- configuração de GitHub Pages.

## GitHub Pages

A página estática está localizada em `docs/` e apresenta:
- perfil e propósito do Study Hub;
- disciplinas atuais;
- projetos do portfólio;
- links para GitHub e LinkedIn.

A publicação é configurada por GitHub Actions no arquivo `.github/workflows/pages.yml`.
