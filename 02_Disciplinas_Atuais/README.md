# Disciplinas Atuais

Esta pasta organiza as disciplinas do semestre atual. Cada disciplina segue a mesma estrutura:

- `Atividades_e_Entregas`: atividades, trabalhos e entregas avaliativas.
- `Anotacoes_e_Resumos`: anotacoes de aula, resumos e referencias de estudo.
