⚠️ Alerta Vermelho: Proteja-se contra a "Nota Zero"

Atenção Crítica de Protocolo:

O edital especifica que links privados ou inacessíveis (Acesso Negado) resultam em Nota Zero automática. Antes de submeter o PDF, certifique-se de realizar o teste em uma aba anônima do navegador para:

  • O link do seu repositório no GitHub (deve estar como Público).
  • O link do documento Google Docs (deve estar configurado como Qualquer pessoa com o link -> Leitor).
  • O link do vídeo no YouTube (deve estar como Público ou Não Listado, e nunca Privado).
